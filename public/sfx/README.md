# Placeholder sound effects

The `.wav` files here are plain synthetic tones generated by
`scripts/make-placeholder-sfx.mjs`. They only exist so you can hear the timing.
To use real sounds, drop a file with the same name into this folder (keep
names, or edit the `SFX` list in `src/JYPinBoot/JYPinBoot.tsx`). Use assets
you have the rights to.

| File          | Plays when                           | Wanted feel                      | Placeholder length |
| ------------- | ------------------------------------ | -------------------------------- | ------------------ |
| `click.wav`   | "enter" pressed on `> JYPin.exe`     | subtle keyboard / UI click       | 0.1s               |
| `confirm.wav` | `✓ system ready` appears             | soft confirmation                | 0.4s               |
| `alert.wav`   | `CURIOSITY SIGNAL DETECTED` snaps in | short alert beep, not harsh      | 0.3s               |
| `pop.wav`     | orange dot appears                   | soft, cute pop                   | 0.15s              |
| `success.wav` | `curiosity module initialized.`      | subtle success cue               | 0.5s               |

Timing lives in the `SFX` list next to `BEATS`: each cue follows its visual
beat, with an optional `offset` (frames) and `volume` (0–1).
